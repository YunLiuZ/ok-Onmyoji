# ok-Onmyoji

基于 [ok-script](https://github.com/ok-oldking/ok-script) 开发的《阴阳师》自动化工具。

支持多开、一键多任务、定时任务以及多种日常与战斗任务，支持后台运行。

## 下载

[下载最新版本](https://github.com/YunLiuZ/ok-Onmyoji/releases/latest){ .md-button .md-button--primary }

[GitHub 仓库](https://github.com/YunLiuZ/ok-Onmyoji){ .md-button }

## 主要功能

- 多开与一键多任务
- 定时任务
- 魂土、困二八、觉醒
- 活动爬塔
- 每日签到、式神委派、寄养
- 个人突破、寮突破等日常任务

## 使用说明

软件通过图像识别及 Windows 用户接口与游戏进行交互，不读取游戏内存，不修改游戏文件。

推荐使用 MuMu 模拟器，并使用 ADB 截图以支持后台运行。
